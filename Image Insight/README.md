# 🧠 AI Image Analyzer

Welcome to **AI Image Analyzer** – a simple yet powerful desktop app that uses machine learning to understand your images!  
Built with 🐍 Python, this app uses 🤖 AI models to generate captions and identify artistic styles.

---

## ✨ Features

- 📤 **Select any image** (`.jpg`, `.jpeg`, `.png`)
- 🖼️ **Auto-generated caption** using [BLIP](https://huggingface.co/Salesforce/blip-image-captioning-base)
- 🎨 **Style detection** using [CLIP](https://huggingface.co/openai/clip-vit-base-patch32)  
  *Supports realism, anime, surrealism, etc.*
- 📐 **Size & DPI info**  
- 🖼️ **Live preview with border**
- ⚡ **No external GUI libraries needed!** (uses `tkinter`)
